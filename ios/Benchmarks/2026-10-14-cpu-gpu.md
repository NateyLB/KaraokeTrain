The run completed, emitted the expected ten seconds of two-channel 44.1 kHz output, and reported no thermal-state change. Total physical memory is not the app's/model's working set.

Overlap, first prediction, Swift processing and output inspection are included. Core ML's specialization cache may already have been populated; a fresh MLModel instance is not evidence of an uncached load. Do not extrapolate this 1.547 ratio directly to a whole song.
